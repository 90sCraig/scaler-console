Still cannot find it?

If automatic recovery cannot run, temporarily set this computer’s Ethernet address to reach 192.168.1.39.

  1. Open Network Connections in Windows.
  2. Open Ethernet properties, then IPv4 Properties.
  3. Select Use the following IP address: 192.168.1.10, mask 255.255.255.0, no gateway.
  4. After moving the scaler, restore automatic IP and DNS.
